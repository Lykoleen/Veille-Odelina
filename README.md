## Portée des recommandations

Les dossiers distinguent les observations, les textes proposés et les évolutions à construire. Les sources sont datées et cliquables. Les consignes d'entretien doivent être confirmées par référence, notamment pour la finition PVD et les ornements.

Aucune recommandation de cette étude n'a été mise en ligne sur la boutique et aucun fichier du dépôt applicatif Odelina n'a été modifié.
